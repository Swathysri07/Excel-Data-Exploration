# Excel Data Exploration

## Project Overview

This project focuses on basic data exploration and analysis using Microsoft Excel. A product dataset is used to perform calculations, analyze product prices, categorize products, and extract specific information from Product IDs.

## Dataset Description

The dataset contains the following columns:

- **Product ID** – Unique identification of each product.
- **Product Name** – Name of the product.
- **Brand Name** – Brand associated with the product.
- **Price ($)** – Price of each product.
- **Quantity** – Available product quantity.
- **Category** – Product category.

## Project Objectives

- Calculate basic statistical values from the product dataset.
- Identify the minimum and maximum product prices.
- Categorize products based on their price.
- Perform conditional calculations based on product categories and prices.
- Extract specific characters from Product IDs.

## Excel Functions Covered

| Function | Purpose |
|---|---|
| SUM | Calculates the total of numerical values. |
| COUNT | Counts cells containing numbers. |
| AVERAGE | Calculates the average value. |
| MIN | Identifies the minimum value. |
| MAX | Identifies the maximum value. |
| IF | Categorizes products based on price conditions. |
| SUMIF | Calculates the total price for a specific category. |
| COUNTIF | Counts products with prices below $100. |
| LEFT | Extracts the first two characters from Product ID. |
| RIGHT | Extracts the last two characters from Product ID. |
| MID | Extracts characters from the middle of Product ID. |

## Project Tasks

1. **Basic Calculations:** Total, count, and average calculations.
2. **Price Analysis:** Identification of minimum and maximum prices.
3. **Price Categorization:** Classification into High Price and Standard Price.
4. **Conditional Analysis:** Electronics category total price and count of products priced below $100.
5. **Text Extraction:** Creation of Day, Month, and Country Code columns using Product ID.
